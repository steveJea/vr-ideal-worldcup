# VR 이상형 월드컵

Violence Royale 히로인 이상형 월드컵 티저입니다. 히로인 데이터와 초상화는 `VR_DATA.csv`, `img/bt_img/` 를 그대로 쓰고, 화면은 모바일에서 두 명 중 한 명을 고르는 토너먼트입니다.

- 전체 순위는 Cloudflare Worker 와 D1 에 우승 횟수만 모읍니다.
- 결과 공유는 X, 링크 복사, 기기 공유 시트를 사용합니다.
- 공식 채널과 카카오톡 버튼은 `js/config.js` 가 비어 있으면 숨겨집니다.

배포와 미리보기 주소는 [DEPLOY.md](DEPLOY.md) 를 보세요. 프로덕션 도메인 `wcup.mbbs.kr` 은 이 설정에 연결되어 있지 않습니다.
